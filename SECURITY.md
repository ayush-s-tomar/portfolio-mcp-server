# Security Policy

## Supported versions

Only the latest release on PyPI is supported.

## Reporting a vulnerability

Please do not open a public issue. Report it privately: open the Security tab of this repository and choose "Report a vulnerability".

Include what you found, how to reproduce it, and the affected version. I aim to reply within 7 days.

## Scope

This server runs locally over stdio and needs no credentials. Reports about the server code, its dependencies, or the packaging are in scope.
